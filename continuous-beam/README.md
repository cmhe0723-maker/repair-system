# 連續梁分析與設計 / Continuous Beam Analysis & Design

單一檔案網頁工具（`index.html`），直接用瀏覽器開啟即可，不需安裝或伺服器。

## 功能
- 設計規範：AISC 360-22 **LRFD**（1.4D、1.2D+1.6L）或 **ASD**（D、D+L）
- 載重：集中載重、集中彎矩、均佈、三角形、梯形分佈載重；分靜載重 D / 活載重 L，可計入自重
- 材料：A36、A572 Gr.50、A992、SS400、SN400B、SN490B、SM490 或自訂；斷面：JIS/CNS H 型鋼、AISC W 型鋼或自訂尺寸
- 支承：固定端、鉸支承、滾支承、自由端（可做懸臂與外伸）
- 語言：繁體中文、English、ไทย、Bahasa Indonesia
- 單位：SI (kN, m, MPa)、MKS (tf, m, kgf/cm²)、US (kip, ft, ksi)
- 圖形：載重圖、剪力圖、彎矩圖、變形圖、反力圖
- 檢核：撓曲（F2 側向扭轉挫屈含 Cb、F3 翼板局部挫屈）、剪力（G2.1）、使用載重撓度
- 列印、轉存 PDF（需網路載入 html2pdf；離線時改用列印對話框「另存為 PDF」）
- 另存新檔 / 開啟舊檔（`.beam.json`），並自動暫存於瀏覽器

## 分析方法
直接勁度法（Euler-Bernoulli 梁元素），每跨細分並在載重位置加節點，分佈載重採一致節點力，元素內剪力與彎矩依載重積分求得精確值。

## 限制
- 僅適用雙對稱 I/H 形斷面，性質依板件尺寸計算（忽略圓角）。
- 腹板非結實時（AISC F4/F5）會顯示警告，未另行計算。
- 未考慮活載重棋盤式排列（pattern loading）。
- 本工具供教學與初步設計參考，正式設計請由專業技師複核。
